# Host integration

HostTanyaAITheme.swift menunjukkan fallback semantic Colors dari aset aplikasi.
Pastikan font dan palette diganti dengan Figma/brand milik host. Constructor
host terbaru dan bridge dokumen/PIN ada di
[HOST_INTEGRATION.md](../../docs/HOST_INTEGRATION.md) dan
[FIGMA_CHAT_UI.md](../../docs/FIGMA_CHAT_UI.md).

Otorisasi memakai halaman existing host dan `onHostFlow` completion. Tidak ada
adapter PIN internal atau ketergantungan SDK vendor pada paket UI.
